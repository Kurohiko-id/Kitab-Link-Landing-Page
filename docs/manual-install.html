Manual Installation

Setup dari nol pakai VPS + Docker + Caddy sebagai reverse proxy. Cocok kalau mau kontrol penuh atau udah ada app lain di server yang sama.

Login SSH

Masuk ke server pakai user & IP publik kamu, lalu update sistemnya.

Login SSH 
ssh username@PUBLIC_IP
Update sistem 
sudo apt-get update && sudo apt-get upgrade -y

Firewall (UFW)

Buka port yang dibutuhin doang: SSH, HTTP, HTTPS.

Izinkan SSH 
sudo ufw allow OpenSSH
Izinkan HTTP (80) 
sudo ufw allow 80/tcp
Izinkan HTTPS (443) 
sudo ufw allow 443/tcp
Aktifkan firewall 
sudo ufw enable

Install Docker

1. Tambah repo resmi Docker:

Install ca-certificates & curl 
sudo apt-get install -y ca-certificates curl
Bikin folder keyrings 
sudo install -m 0755 -d /etc/apt/keyrings
Download GPG key Docker 
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
Kasih izin baca 
sudo chmod a+r /etc/apt/keyrings/docker.asc
Daftarin repo Docker 
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu \
  $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

2. Install Docker Engine + Compose plugin:

Update daftar paket 
sudo apt-get update
Install Docker Engine 
sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

3. Biar docker gak perlu sudo tiap kali, lalu verifikasi:

Tambah user ke grup docker 
sudo usermod -aG docker $USER
Aktifkan grup baru 
newgrp docker
Cek versi Docker 
docker --version
Cek versi Compose 
docker compose version

Struktur ~/apps

Satu folder buat Caddy (reverse proxy), satu folder buat Kitab Link, plus network Docker bersama biar keduanya bisa saling ngobrol.

Bikin folder Caddy 
mkdir -p ~/apps/proxy
Bikin folder Kitab Link 
mkdir -p ~/apps/kurohiko
Bikin network Docker 
docker network create proxy

Caddyfile Kosong

Site block per-domain ditambah belakangan, satu-satu, pas app-nya siap.

Masuk folder Caddy 
cd ~/apps/proxy
Bikin Caddyfile kosong 
touch Caddyfile

Jalankan Caddy

Compose ini cuma buat container Caddy dulu — belum ada mount buat Kitab Link sama sekali, itu ditambahin belakangan (butuh docker compose up -d ulang buat pickup mount baru, reload doang gak cukup).

Bikin docker-compose.yml Caddy 
cat > docker-compose.yml << 'EOF'
services:
  caddy:
    image: caddy:2-alpine
    container_name: caddy
    restart: unless-stopped
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./Caddyfile:/etc/caddy/Caddyfile
      - caddy_data:/data
      - caddy_config:/config
    networks:
      - proxy

networks:
  proxy:
    external: true

volumes:
  caddy_data:
  caddy_config:
EOF
Jalankan Caddy 
docker compose up -d

Atur DNS

Di Cloudflare (atau DNS provider kamu), arahkan domain ke IP server sebelum lanjut — biar pas Caddy minta sertifikat HTTPS nanti, domainnya udah nunjuk ke server yang bener.

  • Record A — root domain (@) arahin ke IP publik server.
  • Record CNAME — www arahin ke root domain.

Download Compose

Ambil compose file resmi Kitab Link di folder ~/apps/kurohiko.

Masuk folder Kitab Link 
cd ~/apps/kurohiko
Download compose resmi 
curl -O https://raw.githubusercontent.com/Kurohiko-id/Kitab-Link-Self-Hosted/main/docker-compose.yml

Jalankan Kitab Link

File default publish port 3000 ke host DAN gak join network apapun — wajar, itu ditulis buat orang yang belum punya reverse proxy. Kita timpa jadi versi ini: ganti nama service (nama service = network alias, harus unik & jelas), lepas ports (cuma diakses lewat Caddy), tambah networks.

Timpa jadi versi custom 
cat > docker-compose.yml << 'EOF'
services:
  kitab-link:
    image: ghcr.io/kurohiko-id/kitab-link-self-hosted:latest
    container_name: kurohiko
    volumes:
      - kitab-link-data:/app/data
    restart: unless-stopped
    networks:
      - proxy

networks:
  proxy:
    external: true

volumes:
  kitab-link-data:
EOF
Jalankan container 
docker compose up -d

Tambah Site Block

Balik ke folder Caddy, tambahin site block buat domain kamu — ganti kurohiko.id dengan domain kamu sendiri.

Masuk folder Caddy 
cd ~/apps/proxy
Tambah site block ke Caddyfile 
cat >> Caddyfile << 'EOF'

kurohiko.id, www.kurohiko.id {
    reverse_proxy kurohiko:3000
}
EOF

Validate & Reload

Cek dulu syntax-nya bener sebelum reload, biar Caddy gak crash gara-gara typo.

Validate config 
docker exec caddy caddy validate --config /etc/caddy/Caddyfile
Reload Caddy 
docker exec caddy caddy reload --config /etc/caddy/Caddyfile

Buat Akun Admin

Ambil token setup 
docker logs kurohiko 2>&1 | grep "Setup token"

Copy token-nya, buka https://your-domain.id/setup (masih DNS only, tetep bisa diakses biasa), isi username + password + token. Selesai — Kitab Link kamu udah jalan di belakang Caddy dengan HTTPS otomatis.

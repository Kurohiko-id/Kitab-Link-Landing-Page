Kenapa Kitab Link?

Dibangun oleh Kurohiko atas dasar keresahan menggunakan layanan Link-in-Bio yang ada.

Bukan sekedar Link in Bio Biasa, tapi Kitab Link ngasih kebebasan, dan tentunya kalian bisa request feature / fork sendiri.

Streamer Friendly

Bisa dikontrol langsung dengan Stream Deck melalui REST API yang aman dan scoped. Ganti status link sambil live tanpa ribet.

Multi-page Asli

Satu akun jadi Hub untuk page mu yang lain. Masing masing page bisa terhubung ke Custom Domain.

Tanpa Biaya Per-Page

Linktree & sejenisnya narikin biaya per fitur/per page. Di sini satu install = unlimited page, selamanya.

Kasih Password di Halaman

Bikin halaman khusus rate card atau info rahasia yang dilindungi password atau temporary password yang kadaluarsa setelah beberapa jam/hari.

Otomasi Lengkap

Mau link Saweria/Trakteer hanya muncul saat Stream? Bisa. Mau link muncul di jam/hari tertentu? Bisa. Ada info otomatis kalau kita lagi Live Streaming!

Keamanan Serius

Dilindungi Argon2id hashing, 2FA (TOTP) Google Authenticator-style, password per-page, hingga setup token sekali-pakai yang aman.

Kustomisasi Tema Mendalam

Theme engine berbasis token: background aurora/gradient/foto, font terkurasi Google, gaya tombol glassmorphism, hingga custom CSS.

Data Sepenuhnya Punya Lu

Disimpan dalam satu file SQLite di server sendiri. Export/import kapan aja. Gak ada vendor yang bisa mendadak matiin akses lu.

Ringan & Super Cepat

Halaman public server-rendered dengan minim JS di Client. Gak ada tracking script berat yang bikin lemot.

Head-to-Head

Kitab Link vs Linktree-style SaaS

Alasan kenapa lebih memilih Kitab Link untuk jangka panjang.

Aspek Linktree-style SaaS Kitab Link
Biaya Langganan bulanan, fitur terkunci per tier Sekali deploy, selamanya punya sendiri
Data & Privasi Disimpan di server vendor pihak ketiga 1 file SQLite, aman di server lu sendiri
Jumlah Page Dibatasi atau berbayar per page tambahan Unlimited dalam 1 akun mandiri
Custom Domain Fitur premium (harus bayar mahal) Bawaan, per-page, gratis selamanya
Keamanan 2FA Kadang absen di tier gratis Bawaan, TOTP + backup code OWASP
Streamer Friendly Gak ada fitur buat streamer Link nempel ke Saweria/Trakteer, auto-muncul pas Live
Automasi Fitur otomatisasi terbatas atau harus upgrade paket Jadwalin link nongol/hilang otomatis sesuai jam atau status Live
Keamanan & Integrasi

Otomasi Canggih & Keamanan Kelas Perusahaan

Kitab Link tidak main-main soal keamanan dan fleksibilitas developer. Dilengkapi fitur otomasi yang dirancang khusus untuk streamer dan kreator aktif.

Deteksi YouTube Live Otomatis

Grup link khusus live akan muncul otomatis saat lu streaming dan hilang pas selesai.

Argon2id & 2FA TOTP

Standar hashing OWASP mutakhir dengan autentikasi dua faktor ala Google Authenticator.

REST API & Stream Deck

Scoped Bearer token siap integrasi langsung dengan hardware Stream Deck atau webhook kustom.
